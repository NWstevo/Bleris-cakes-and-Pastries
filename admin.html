Connect the database first

This admin panel isn't connected to Supabase yet, so there's nothing to log in to.

  1. Create a free project at supabase.com.
  2. Open the SQL Editor and run the script in supabase/setup.sql from this project.
  3. In Project Settings → API, copy the Project URL and the anon public key.
  4. Paste both into supabase-config.js and redeploy the site.
  5. In Supabase, go to Authentication → Users and add yourself with an email and password — that's your staff login.
